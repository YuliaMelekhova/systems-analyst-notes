# Prompt Library

Prompts shaped for recurring analytical tasks, kept as references instead of rewritten from scratch each time. Workshop notes into a structured requirements document, features into user stories with acceptance criteria, acceptance criteria into test cases, a draft document into a gap analysis.

A prompt belongs here when it has produced usable output on real work more than once, and when the structure of it is the point. Something that only works with one model, or only on one document, is a note rather than a library entry.

Each entry states what it takes as input, what it returns, and where the output still needs a human pass before anything is built on it. A prompt with no stated review step is incomplete.
