# Knowledge Packs

Reference material on the standards this system touches, written up once and reused across every requirement that needs it instead of re-researched each time. BABOK, OpenAPI, ISO 20022, Open Banking Standards, RFC 9110 and its relatives, Microsoft Manual of Style.

A pack belongs here when the standard is referenced by more than one piece of work and the useful version of it is shorter than the specification. Each one states what changes in a system, what breaks in an existing integration, and which questions a specification has to answer. A summary of the standard is not a pack.

Standards move, so packs carry a verification note and are expected to be edited rather than frozen.
